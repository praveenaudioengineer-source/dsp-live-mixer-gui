# 🎛️ DSP Live Mixer (GUI)

Real-time audio mixer using Python and DSP.

## 🔥 Features
- Live microphone input
- Gain control
- 3-band EQ (Bass / Mid / Treble)
- GUI sliders
- Real-time processing

## 🧠 Tech Used
- Python
- NumPy
- SciPy
- SoundDevice
- Tkinter

## 📦 Install
pip install numpy scipy sounddevice

## ▶️ Run
python main.py

## 🎯 Purpose
Audio engineering + DSP learning project
